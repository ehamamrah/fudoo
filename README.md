# Fudoo

Inventory and purchasing service for a single-branch burger restaurant.

> Work in progress. Full README (run, tests, data model, decisions, AI usage, next steps) lands at the end of the build.

## Quick start

```bash
make up      # postgres + Django API (:8000) + React UI (:5173)
make seed    # sample ingredients, suppliers, Classic Burger recipe
make test    # backend + frontend tests
```

See `AGENTS.md` for conventions and `docs/api-contract.md` for the API.
